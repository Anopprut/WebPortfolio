LINE Notify เลิกให้บริการแล้ว ใช้อะไรแทนใน n8n

คำตอบสั้น: LINE Notify หยุดให้บริการแล้ว (ประกาศ 7 ต.ค. 2024 ปิดจริง 31 มี.ค. 2025) ถ้า workflow n8n ของคุณเคยส่งแจ้งเตือนผ่านโหนด LINE ที่ใช้ Notify มันจะไม่ทำงานอีก ทางแทนที่ LINE แนะนำคือ Messaging API ซึ่งใช้ได้ผ่านโหนด HTTP Request ของ n8n โดยไม่ต้องติดตั้งอะไรเพิ่ม

ตรวจข้อมูลเมื่อ 2026-10-10 จาก ประกาศ End of life ของ LINE Developers และกระทู้ ขอโหนด LINE ใหม่แทน Notify ในชุมชน n8n

ขั้นตอนย้ายแบบเร็วที่สุด (ผ่าน HTTP Request)

  1. สร้าง Messaging API channel: เข้า LINE Developers Console → สร้าง Provider → สร้าง Messaging API channel (ผูกกับ LINE Official Account)
  2. เก็บ 2 ค่า: Channel access token (ใช้ส่งข้อความ) และ Channel secret (ใช้ตรวจลายเซ็น webhook) เก็บใน Credentials ของ n8n อย่าใส่ในตัว workflow
  3. หาผู้รับ: ต้องมี userId ของคนที่เพิ่มบอตเป็นเพื่อนแล้ว (ได้จาก webhook event) หรือ groupId ของกลุ่มที่เชิญบอตเข้า
  4. เพิ่มโหนด HTTP Request ตั้งค่าตามด้านล่าง
POST https://api.line.me/v2/bot/message/push
Authorization: Bearer {Channel access token}
Content-Type: application/json

{
  "to": "U1234567890abcdef...",
  "messages": [
    { "type": "text", "text": "ออเดอร์ใหม่เข้าแล้ว" }
  ]
}

ข้อความหนึ่งคำขอใส่ได้ไม่เกิน 5 ข้อความ (ข้อกำหนด OpenAPI ทางการของ LINE)

หรือใช้โหนดชุมชน

มีโหนดชุมชนบน npm ที่ครอบ Messaging API อยู่แล้ว เช่น n8n-nodes-line-messaging (MIT) มีส่ง ตอบ multicast ดึงโปรไฟล์ และตัวรับ webhook ที่ตรวจลายเซ็นให้ ผมตรวจเมื่อ 2026-10-10 พบว่ามีโหลดราว 1,100 ครั้งต่อเดือน เวอร์ชันล่าสุดบน npm เผยแพร่เมื่อเดือนตุลาคม 2025 และตัวโปรเจกต์บน GitHub ยังมีการอัปเดตล่าสุดเมื่อเดือนกันยายน 2026 แต่เป็นโหนดของบุคคลที่สาม ควรอ่านโค้ดและตรวจการดูแลก่อนใช้ในงานจริง

ข้อควรระวัง

  • การส่งข้อความหาผู้ใช้ไม่ได้ฟรีไม่จำกัด ให้ตรวจโควตาข้อความของแพ็กเกจ LINE Official Account ที่ใช้อยู่
  • Notify เดิมส่งเข้า "ตัวเรา" ได้ง่าย แต่ Messaging API ต้องให้ผู้รับเพิ่มบอตเป็นเพื่อนก่อน จึงเปลี่ยนวิธีคิดเล็กน้อย
  • บทความนี้อธิบายจากเอกสารทางการ ผมไม่ได้ทดสอบส่งข้อความจริงกับ channel ของผู้อ่าน
อยากให้ผมทำให้? รับทำระบบอัตโนมัติ n8n, LINE OA / Telegram Bot และงานเชื่อมระบบสำหรับร้านค้าและทีมเล็ก ดูบริการของผมบน Fastwork ส่งโจทย์มาให้ประเมินขอบเขตและราคาก่อนจ้างได้

คำถามที่พบบ่อย

LINE Notify ยังใช้ได้ไหม?

ไม่ได้ LINE ประกาศปิดบริการ และตั้งแต่ 1 เมษายน 2025 ฟีเจอร์และ API ของ LINE Notify ใช้งานไม่ได้ทั้งหมด LINE แนะนำให้ย้ายไปใช้ Messaging API

ใช้ Messaging API ส่งเข้ากลุ่มได้ไหม?

ได้เมื่อเชิญบัญชี LINE Official Account (บอต) เข้ากลุ่มแล้วใช้ groupId เป็นผู้รับ แต่ต้องตรวจเงื่อนไขและโควตาข้อความของแพ็กเกจที่ใช้อยู่ในเอกสาร LINE

ต้องมีบัญชี LINE Official Account ไหม?

ต้องสร้าง Messaging API channel ใน LINE Developers Console ซึ่งผูกกับ LINE Official Account และผู้รับต้องเพิ่มบัญชีนั้นเป็นเพื่อนก่อนจึงจะส่งข้อความหากันได้
