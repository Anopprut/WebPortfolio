คู่มือ n8n + LINE (ภาษาไทย)

ทุกเรื่องตรวจกับเอกสารทางการ ณ 2026-10-10 และบอกชัดเจนว่าส่วนไหนยังไม่ได้ทดสอบกับบัญชีจริง

LINE Notify เลิกให้บริการแล้ว ใช้อะไรแทนใน n8n

LINE Notify ปิดบริการ 31 มี.ค. 2025 วิธีส่งข้อความเข้า LINE จาก n8n ต่อด้วย Messaging API: ตั้งค่า token ส่งผ่าน HTTP Request หรือโหนดชุมชน พร้อมข้อควรระวัง

Reply, Push, Multicast, Broadcast ของ LINE ต่างกันอย่างไร

เปรียบเทียบ 4 วิธีส่งข้อความของ LINE Messaging API พร้อมขีดจำกัดที่เอกสารทางการระบุ (5 ข้อความต่อคำขอ, multicast สูงสุด 500 คน) และวิธีเลือกใช้ใน n8n

n8n Cloud หรือโฮสต์เอง: เลือกอย่างไร (ราคาปัจจุบันจากหน้าทางการ)

เปรียบเทียบ n8n Cloud (Starter €20, Pro €50 ต่อเดือน จ่ายรายปี) กับ Community Edition โฮสต์เอง พร้อมคำถามที่ควรตอบก่อนเลือก ตรวจจากหน้าราคาทางการ

สร้างบอต LINE ตอบอัตโนมัติด้วย n8n: ตั้งแต่สร้าง channel ถึงตอบกลับ

ขั้นตอนทำบอต LINE ตอบข้อความด้วย n8n: สร้าง Messaging API channel ตั้ง webhook ตรวจลายเซ็น อ่านข้อความจาก replyToken แล้วตอบกลับ พร้อมนิพจน์ที่ใช้ได้จริง

LINE Rich Menu ผ่าน API: สร้าง อัปโหลดรูป ตั้งเมนู (n8n)

วิธีสร้าง Rich Menu ของ LINE ด้วย API 3 ขั้น: สร้างเมนู อัปโหลดรูปไปที่ api-data.line.me แล้วตั้งเป็นเมนูตั้งต้นหรือผูกกับผู้ใช้ พร้อม JSON ตัวอย่างและคำขอสำหรับ HTTP Request ใน n8n

อยากให้ผมทำให้? รับทำระบบอัตโนมัติ n8n, LINE OA / Telegram Bot และงานเชื่อมระบบสำหรับร้านค้าและทีมเล็ก ดูบริการของผมบน Fastwork ส่งโจทย์มาให้ประเมินขอบเขตและราคาก่อนจ้างได้
